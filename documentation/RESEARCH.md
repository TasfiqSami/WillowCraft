# Design research and benchmarks

## Scope and honesty note

The brief calls for at least 100 distinct Minecraft server websites and webstores, with 20 deeply inspected. I did **not** complete a 100-site audit or a 20-site visual deep dive, so this document does not claim either. The first pass opened 23 relevant website, storefront, product-theme, platform-documentation and skin-service pages across 21 distinct domains. A further targeted review opened additional network, store and platform pages; those are recorded separately below. The fetcher exposed page text and page structure; it did not provide a complete visual/browser audit for every page. Some candidate sites and design listings were inaccessible or only appeared in search results, and those were not counted as reviewed.

This remains a documented benchmark set, not a substitute for the requested 100-site study. The additional pages were inspected for available structure, copy and purchase flow; a hands-on, responsive visual comparison of 20 complete sites remains outstanding.

## Findings translated into WillowCraft decisions

- **Team structure:** ownership, management, development, infrastructure, marketing and moderation are explicit departments. Each person appears once; multiple responsibilities are shown as role badges.
- **Minecraft identity:** cards use Crafty head renders; individual profiles load one full-body render. When the render service fails, the UI says the skin render is unavailable rather than showing generated initials as a fake avatar.
- **Profile download:** the server-side endpoint resolves the actual Mojang skin texture. It does not download the Crafty character render. Mojang's documented HTTP texture URL is upgraded to HTTPS only after the host and path are validated.
- **Store content:** products come from src/config.js. The only configured top-up reference price is 700 Points for 330 BDT; other quantities do not receive an invented price.
- **Checkout:** the repository has no payment provider, order database, signed payment webhook or in-game delivery worker. Checkout stays disabled; a cart preview is not presented as a purchase.
- **Visual identity:** deep forest greens remain primary, gold is restrained to ownership/featured states, and the pixel-grid geometry is CSS-only. No third-party branding or assets are copied.

## Remaining research gap

The 100-site target remains open. The references above informed the implementation pass, but they should not be presented as 100 completed site audits. Any later benchmark expansion should record the URL, what was actually inspected, the useful pattern and the specific WillowCraft decision it informs.


### Skin lookup resiliency

The skin-download endpoint tries the current Minecraft Services username lookup, Mojang's alternate current-name lookup route, then the legacy username route. Mojang may return HTTP 429 when the public username lookup is rate-limited; the API responds with HTTP 503 and Retry-After rather than disguising that condition as a missing player. Successful PNGs are cached in memory for five minutes per warm function instance and concurrent requests for the same username share one upstream lookup. Vercel's response cache can reuse successful responses according to the existing Cache-Control headers.

## Consolidated design decisions

- Prioritise the server identity, address and joining instructions before the store.
- Use one consistent navigation and footer so players can always reach team, community, rules, support and policy pages.
- Make staff discoverable through departments and individual profiles, while using authentic Minecraft skins only for the actual download.
- For stores, separate category navigation, perk comparison, exact prices, player identity, cart, payment provider, fulfilment timing and support. These are distinct pieces of a purchase system, not interchangeable UI decorations.
- Do not copy competitor sales language, refund rules, uptime figures, online counts, payment badges or fulfilment promises into WillowCraft without owner-verified facts.
- Keep WillowCraft checkout disabled until a real merchant/provider, order storage, verified payment callback, delivery worker/commands, refund terms and support ownership are configured.
